## 🛠️ Proyectos Clave Seleccionados

### 1. Motor de Búsqueda Jurisprudencial (Saleman)
- **Propósito**: Búsqueda e indexación de ultra-baja latencia sobre jurisprudencia y normativa sin contención de concurrencia.
- **Stack**: Rust, Tantivy v0.26, SQLite WAL, Python.
- **Diferencial**: Respuestas en submilisegundos en hardware estándar sin depender de servicios externos.

### 2. Buscador Semántico Offline (LocalSearchEngine)
- **Propósito**: Búsqueda conceptual y similitud vectorial local-first.
- **Stack**: LanceDB, PyArrow, Python, Svelte.
- **Diferencial**: Privacidad absoluta y cero fuga de información fuera del host local.

### 3. Pipeline OLAP InmobiliariaData
- **Propósito**: Ingesta, enriquecimiento y normalización de avisos inmobiliarios en Lima.
- **Stack**: DuckDB, Polars, PyArrow.
- **Diferencial**: Procesamiento columnar de alta velocidad libre de cuellos de botella en memoria RAM.

### 4. Portafolio Técnico & Simulador Tantivy
- **Propósito**: Showcase interactivo con micro-simulador en vivo de búsqueda en Rust sobre cliente web.
- **Stack**: HTML5, Tailwind CSS, JavaScript Vanilla, Cloudflare Pages.
