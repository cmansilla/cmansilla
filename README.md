## 🛠️ Repositorios de Código Abierto & Showcase Técnico

### 1. [Algoritmo Jurídico v4](https://github.com/cmansilla/algoritmojuridico-v4)
- **Propósito**: Motor tri-políglota para búsqueda y orquestación jurídica sobre jurisprudencia y normativa peruana.
- **Stack**: **Rust** (Tantivy v0.26 mmap P99 <0.42ms) + **Go** (Model Context Protocol Gateway <35MB) + **Python** (Multi-Agent Orchestrator).
- **Diferencial**: Separación estricta en tres planos de ejecución con validación neurosimbólica de citas auténticas.

### 2. [Audit CPE Engine](https://github.com/cmansilla/audit-cpe-app)
- **Propósito**: Motor concurrente de auditoría tributaria y triaje masivo de Comprobantes de Pago Electrónicos (XML UBL 2.1) ante SUNAT.
- **Stack**: **Go 1.23 Pure**, `sync.RWMutex`, patrón **SingleFlight** y UI web embebida.
- **Diferencial**: Binario autocontenido (~12MB) para Linux y Windows `.exe` con zero-dependencies y consumo en reposo <35MB.

### 3. [LexProof Forensic Engine](https://github.com/cmansilla/lexproof-forensic-engine)
- **Propósito**: Preservación digital, cadena de custodia y peritaje informático conforme a **ISO/IEC 27037** e **ISO/IEC 27042**.
- **Stack**: **Python 3.11**, `cryptography` (SHA-256 + BLAKE3 dual hashing), `PyAV`, 18 test suites unitarias.
- **Diferencial**: Motor CAF v3.0 contra EXIF Spoofing, manipulación por IA generativa y dictámenes periciales admisibles bajo **FRE 902(14)**.

### 4. [Legal GraphRAG Engine](https://github.com/cmansilla/legal-graph-rag)
- **Propósito**: Grafo de conocimiento relacional y RAG jerárquico determinista sobre resoluciones y decretos legislativos.
- **Stack**: **Python**, **SQLite WAL con CTEs recursivas**, `NetworkX`, bucle multi-agente Router/Critic/Strategist.
- **Diferencial**: Expansiones ontológicas en submilisegundos sin la sobrecarga de memoria de bases de datos de grafos distribuidas.
